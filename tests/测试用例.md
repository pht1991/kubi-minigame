## E. 用例统计与回归映射（Handoff 关键）
- **总用例数**：约 50 条（主路径 ~22 / 边界 ~22 / 回归 6）。
- **工程修复后必须回归的用例**（由真机执行人回填）：
  - 建筑升级修复 → TC-BUI-02、TC-BUI-03、TC-BUI-04、TC-REG-01
  - 地图采集修复 → TC-MAP-01、TC-MAP-02、TC-MAP-03、TC-REG-02
  - 地图怪递减 → TC-MAP-05、TC-MAP-07、TC-REG-03
  - 战斗一致性 → TC-MAP-06、TC-EVE-03、TC-DUN-02、TC-REG-04
  - 性能/泄漏 → TC-BAG-05、TC-REG-05、TC-REG-06
  - 存档 → TC-SAV-01 ~ TC-SAV-06
- **阻塞/不适用**用例需在报告中标注原因（如无 Cocos 编辑器无法离线验证 UI 渲染，仅逻辑层可离线跑）。
