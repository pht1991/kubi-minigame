## UI Bug 修复：滚动失效 + msg 不显示（用户截图反馈）
- **问题①（无法滚动）**：`GridComponent.renderCells` 强制把 ScrollView 的 view 设为 content 尺寸并关闭 Mask → view≥content 不滚动 + Mask 关闭内容溢出。修复：删除整段 view 尺寸篡改 + Mask 关闭代码，让 view 保持编辑器预设尺寸、Mask 保持开启，content 比 view 大时自动可滚动
- **问题②（msg 不显示）**：背包/制造用 `pop()` 回列表，但列表 cells 是 push 时的快照，pop 后 UI_REFRESH 只用旧快照重渲，不会重建含 `_lastMsg` 的新 cells。修复：
  1. `types.ts` GridPage 加 `rebuild?: () => GridCellData[]` 回调
  2. `GridComponent.renderPage` 渲染前如有 rebuild 则 `page.cells = page.rebuild()`
  3. MainScene 提取 `buildBagCells()`/`buildCraftCells()` 供 push 与 rebuild 共用，列表页 push 时传入 `rebuild: () => this.buildXxxCells()`
  4. openBagGrid/openCraftGrid 开头加 `this._lastMsg = ''` 防止跨系统串显旧 msg
- 其他列表页（建筑/技能/事件等）pop 回列表时数据也可能过期，但详情页用 replace 自刷新，列表重进即可刷新；暂不加 rebuild，按需再补

## 致命颜色 Bug 修复（用户截图"三级网格颜色不对"）
- **根因**：`GridCell.ts` 的 `drawRoundedBg()` 调用了 `gfx.roundRect()`，但 **Cocos Creator 3.8 的 Graphics 组件没有 `roundRect` 方法**。这导致 `TypeError` 中断 `refresh()`，后续 `cooldownMask.active = false` 和 `borderSprite.color = bgColor` 全部不执行，格子保持 prefab 默认值——CooldownMask 灰色背景(187,187,187)始终显示，文字保持默认白色。
- **修复**：
  1. `drawRoundedBg` → `drawCellBg`，使用 `gfx.rect()` 替代 `gfx.roundRect()`（Cocos 3.8 确认支持）
  2. `borderSprite` 的 `builtinResMgr.get('default-sprite-frame')` 移除，改用 try-catch 容错，避免获取失败再次中断 refresh
  3. 移除 `builtinResMgr` 和 `SpriteFrame` 的无用导入
- **tsc 快速校验**：`GridCell.ts` / `DialogPanel.ts` / `MainScene.ts` 修改后 0 类型错误（仅 node10 moduleResolution 弃用警告）
