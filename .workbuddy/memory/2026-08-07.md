- 用户截图反馈交易弹窗滚动区很小、按钮下方有大片空白。**根因**：`TradePanel` 固定 `panelH=1040`，且 `createScrollList({autoResizePanel:false})` 不调整面板高度，导致内容少时按钮下出现蓝框死区。
  **修复**：移除固定 `PH`；`setRows` 返回 `actualViewH` 后按 `targetPanelH = 90(content 顶部到面板顶) + 130(Header) + actualViewH + 20(滚动区到按钮间距) + 72(按钮) + 30(底部留白)` 计算并 `resizePanel(clamp 380~1040)`；滚动区重新 `list.view.setPosition(0,-130,0)` 贴在 Header 下方；按钮 `by=130+actualViewH+20+36` 紧贴滚动区底部下方，避免与滚动区重叠。tsc 零新增（仍为 46 存量错）。

- 用户要求检查其它面板是否有类似 TradePanel 的"固定高度导致底部空白"问题。
  **全面板审计（8 个 ModalPanel 子类 + ProgressOverlay）结论：除已修的 TradePanel 外，均正确处理高度，无类似 bug**：
  - 走基类默认 `autoResizePanel:true`（setRows 自动 resizePanel + 重定位滚动区）：`DialogPanel`(minPanelH300/max900)、`BagPanel`(titleReserve100/bottomReserve20/max1040，minPanelH 默认 380)。二者初始 y 恰好等于 titleReserve，resize 后 repositionScroll 默认 true 自动对齐，无错位/空白。
  - 显式自适应：`EventDetailPanel`/`QuantityPanel`/`ResultModal` 各自 `resizePanel(targetH)`；`HarvestModal`/`TradePanel` 用 `autoResizePanel:false` 但手动 resizePanel（已修）。
  - 固定高度但内容固定、非此 bug 范畴：`BattlePanel`(panelH=880 镜像卡片布局，战斗元素不随数据增减，自己管理日志 scroll)、`ProgressOverlay`(非 ModalPanel 子类，固定 210 全屏进度层：标题+进度条+百分比，内容不增减)。
  **注意**：`autoResizePanel:false` 是高危模式——必须配套手动 resizePanel + 重定位滚动区/下方元素，否则即重现 TradePanel 类死区；新增弹窗若非 HarvestModal/TradePanel 式"Header+滚动区+底按钮"三段式，应优先用默认 `autoResizePanel:true`。
