## 工程化：无头构建 + 噪声 profile gitignore（解决「编辑器自动改文件」痛点 13:43）
- 用户痛点：编辑器/构建进程不断重写 `profiles/v2/packages/{builder,scene,utils}.json` 导致 `git status` 永脏；且每次构建把 `separateEngine` 回退要手动改。
- 方案（已全部落地并推 master ec8ffec）：
  1. **gitignore 3 个噪声文件**：`profiles/v2/packages/{builder,scene,utils}.json` 从版本库 `git rm --cached` 并忽略（`engine.json`/`wechatgame.json` 保留追踪）。编辑器开/关、构建前后都不再污染 `git status`。
  2. **`deploy-wechat.bat`（新增）**：微信小游戏**无头构建**——`CocosCreator.exe --project ... --build "platform=wechatgame;debug=false;buildPath=.../build/wechatgame"`（扁平输出 build/wechatgame/）。流程：构建前递归恢复 separateEngine=true → 构建 → fix-build-config.js(修 libVersion) → 构建后再次恢复 separateEngine=true 并 `git commit` wechatgame.json → `taskkill` 残留 Cocos 进程。
  3. **`deploy-web.bat`（重写）**：修正产物复制目录为 `build/web-mobile/web-mobile/`，并同样构建前/后恢复 separateEngine + 提交 + 杀进程。
  4. **关键认知**：构建微信小游戏**根本不需要开 Cocos 编辑器 GUI**，无头命令行即可；之前「关了编辑器构建还得重开」是误解。
- 验证：separateEngine 恢复脚本对 wechatgame.json 两处（builder.options.wechatgame / builder.taskOptionsMap[...]）模拟回退 false→true 均生效；3 文件 `git check-ignore` 确认被忽略。
