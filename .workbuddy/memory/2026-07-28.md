## deploy-wechat.bat 编码坑（16:33 用户贴报错定位）
- 用户贴出报错：`'rocess.argv[1]' 'uild-config.js' 'ho' '抽棴銆?echo' 不是内部或外部命令` 等——全是中文行乱码 + **紧跟中文的首个 ASCII 字母被吃掉**。
- 根因：`.bat` 用 UTF-8 无 BOM 保存，中文 Windows 的 GBK 代码页读它 → 中文乱码、且吃掉中文后第一个英文字母，导致每行都被当成"命令"报错。`chcp 65001` 只改输出码页、不改 bat 解析码页，救不了。
- 修复：把 `deploy-wechat.bat` **整体改写为纯 ASCII（英文注释/echo + node 字符串也改英文）**，彻底不碰编码。已用 grep `[^\x00-\x7F]` 确认 0 个非 ASCII 字符。中文 Windows 下 ASCII 在 GBK/UTF-8 码页字节完全一致，必能正常解析。
- 教训写入 MEMORY.md「构建部署铁律」：**bat 含中文须存 GBK/UTF-8+BOM；最稳是 bat 全 ASCII**。本仓库后续所有 .bat 一律写英文。
