## 修复 GridComponent topPadding 不生效的根本原因（第三轮）
- **根因**：`renderCells` 中手动计算 `contentY = viewTop - contentTopOffset` 设置 content 位置，但 Cocos ScrollView 在后续帧会自动重置 content 为默认居中，覆盖手动值。格子 `y = -topPadding` 计算本身正确，但 content 未对齐 view 顶部导致被遮罩裁掉
- **修复**：
  - 删除 contentY 计算逻辑（viewT/anchors/offset 全部移除），改为 `setPosition(0, 0, 0)`
  - 新增 `this.scheduleOnce(() => scrollToPercentVertical(1, 0.01, false), 0)`，延后到下一帧确保 ScrollView 初始化完成后再滚动
- **DialogPanel.ts**：topPadding 从 24 调到 30

## 修复文字颜色和首行遮挡的真正根因（第四轮）
- **根因 1：StatusBar timeLabel/tempLabel 未设颜色** — `refresh()` 中只设了 `string`，从未设 `color`，保持 Label 默认白色。场景文件中 StatusBar Bg 也是白色 (255,255,255)，白字白底完全不可见
- **根因 2：GridComponent content 定位 (0,0) 错误** — view anchor 是 (0.5,0.5)，view 顶部在 y=height/2=450。设 content.y=0 把 content 顶部放在 view 中心，ScrollView 钳制到滚动范围底部（远低于 0），首行被 mask 裁掉
- **修复**：
  - **StatusBar.ts**：`timeLabel.color = (60,45,30,255)` 深棕；`tempLabel` 正常时深棕，极寒/酷暑时变红 `(200,50,40)`
  - **GridComponent.ts**：`contentY = viewT.height * (1 - viewT.anchorY)` = 900*0.5 = 450，正确对齐 content 顶部到 view 顶部；`scrollToPercentVertical(1,...)` 改为 `scrollToTop(0)` 立即生效
  - **DialogPanel.ts**：新增 `_scrollView` 字段，`renderOptions` 末尾加 `scrollToTop(0)` 确保弹窗首行可见
  - **场景文件**：StatusBar Bg 从白色改为暖羊皮纸 (245,240,230)；所有 Label（时间/体温/生命/满腹/水分/体力/精神/标题/面包屑/返回）场景默认色从白色改为深棕 (60,45,30) 或对应主题色，消除首帧闪白

## 修复首行遮挡的真正根因（第五轮）
- **根因**：`scrollToTop` 在 view.anchorY=0.5 时计算 content.y=0，把顶部移到 view 中心而非顶部；`topPadding` 计算的是格子中心而非顶部，`y = -topPadding` 让格子顶部贴 content 顶边
- **修复**：
  - 删除 GridComponent 和 DialogPanel 中所有 `scheduleOnce + scrollToTop` 调用，content 保持在 `y=450`（view 顶部）
  - 格子 y 公式改为 `-(topPadding + cellHeight/2)`，topPadding 真正成为格子顶部到 content 顶边的距离
- **确认**：用户验证首行遮挡问题已解决

## 修复 BattlePanel 两个 Bug（用户反馈）

**Bug 1：点技能按钮无反应**
- 根因：`showSkillGrid()` 和 `showItemGrid()` 使用 `getComponentInChildren('DialogPanel')` 字符串方式查找组件，在 Cocos 3.x 中不可靠 → `dialogPanel` 为 null，弹窗从未显示
- 修复：导入 `DialogPanel` 类，改用 `getComponentInChildren(DialogPanel)` 类构造器查找

**Bug 2：道具弹窗在战斗面板下面看不见**
- 根因：MainScene.start() 中 DialogPanel 先 addChild、BattlePanel 后 addChild → Cocos 2D 渲染后添加的在上层，BattlePanel 遮挡 DialogPanel
- 修复：显示弹窗前调用 `dialogPanel.node.setSiblingIndex(parent.children.length - 1)` 将弹窗节点提升到最上层

**附加修复：BattlePanel 构造函数问题**
- 移除 `constructor()` 中 `this._combat = ActionCombat.instance`（Cocos Component 构造函数不应访问外部单例）
