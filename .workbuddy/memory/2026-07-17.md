- **v3 截图反馈3 (e409350)**：

- **v3 构建报错 (aa6afc2)**：
  - Cocos 构建期报 `[Programming] TypeError: Cannot read property 'resolutions' of null`
  - **根因**：v3 重写 TradePanel.ts 时 L137 写成 `private _qty = 1, _mqty = 1, _mnqty = 1;`
    —— 单个 private 修饰符下逗号分隔多个带初始值属性声明，TS 非法（报 `';' expected`）
    —— 此语法错误使 Cocos 模块解析阶段拿到 null → resolutions of null
  - **教训（重要）**：v3 提交前用 transpileModule 已报出这 2 个 `';' expected` 错误，当时误判为"工具限制"而忽略提交，**导致后续构建失败，浪费多轮**。transpileModule 的 Error 级诊断一律视为真实语法错误，绝不可忽略
  - **修复**：拆成三个独立 `private` 声明；全量扫描 39 个 TS 文件确认无其他同类语法错误
