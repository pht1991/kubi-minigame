## 🐛 修复：工具用一次就从背包消失（耐久系统未生效）

### 问题
用户反馈「工具用一次就没了」。根因：`ActionExecutor.execute` 把 require 里的工具类（如 `axe:1` 斧头）当普通材料，用 `useItemThatPlayerHave` **直接从背包扣数量**，而非消耗装备耐久 → 斧头被当消耗品扣光。

### 修复（3 文件）
1. **GameManager.ts**
   - import `ITEM_DATA`
   - 新增 `_getEquipSlot(itemId)`（与 ActionItem.getEquipSlot 一致的槽位推导）
   - `isToolItem(itemId)`：有 `durable` 且能装备 → 是工具
   - `canUseTools(require)`：工具类需已装备 `currentEquip[slot]===itemId` 且 `durableSaveData>=need`，否则返回缺什么
   - `useTools(require)`：扣装备工具耐久，归零则 `delete durableSaveData` + 卸下槽位 + 发 EQUIP_CHANGE
2. **ActionExecutor.ts** `execute`

   - 消耗阶段：材料 `useItemThatPlayerHave`，工具 `useTools`
3. **MainScene.ts** `canMeetResourceRequire`：工具类 require 改判 `canUseTools`（已装备+耐久），与执行逻辑一致

### 行为变化
- 斧头/镐子/锤子等工具：装备后多次使用扣耐久，耐久归零才损坏卸下；背包数量永不因使用减少

## 🐛 修复：装备斧头后仍无法砍树（地点详情页无 rebuild 机制）

### 问题
用户装备了斧头、体力也够，但地图详情页中「树 [砍]」格仍显示置灰不可点击。

3. **新增 `defaultTraderProb(d)`**（缺省概率，数据可加 `prob` 字段覆盖以精确还原原版）：
   - `give==='gold'`（金币商队）→ 1 必出（核心金币来源）
   - `season` 季节商人 → 1 必出（本身稀缺）
   - `type==='upgrade'` 升级商人 → 0.6
   - 其余资源/功能商人 → 0.5
4. **openGoOutList / openMapGrid**：开头 `if (_rolledTraders.length===0) _rolledTraders = rollVisibleTraders()`；商人遍历由 `for (const key in TRADE_DATA)` 全列 → `for (const key of _rolledTraders)` 仅展示在场一批
5. **回家清空缓存**：`onNavChanged`（home 分支）+ `buildHomePage` 开头均 `this._rolledTraders = []` → 下次出门重新随机

### 设计要点
- **弱缓存（每次出门固定一批、回家重摇）**：保证玩家在本次出门期间逛地图/地点/交易时商人群稳定（不会出现"买完东西返回列表商人全变"的怪异感）；回家再出门刷新，贴近"今天镇上来了一批商人"的真实感
- **两入口共用缓存**：出门页与地图页读到同一批 `_rolledTraders`，保持一致
- **概率可调**：TRADE_DATA 每个商人加 `prob?: number` 即可逐条精细控制（目前用 defaultTraderProb 规则默认，未逐条改数据）
