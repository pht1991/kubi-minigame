## 三、P0 关键缺陷（打磨必须收口）

1. **两套战斗解算不一致**：`ActionCombat`（完整：前缀修正/装备减伤/耐久/技能CD）vs `ActionDungeon.battle()`（简化：前缀未接入/忽略减伤/不耗耐久），后者被事件、地图狩猎调用 → 同怪难度/后果不一致。
2. **地图怪数量不递减**：`ActionMap.hunt` 未扣减 `mst.amount`，与采集资源枯竭设计不自洽。
3. **性能**：无对象池（列表全量 destroy+instantiate）、无 `UI_REFRESH` 节流（高频全量 renderPage）。
4. **GridCell**：缺 `onDestroy` 清 `setTimeout`；`ActionItem.ts:3` 过时注释。
