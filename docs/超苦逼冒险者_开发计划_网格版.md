## 一、网格 UI 设计规范

### 1.1 核心原则

**一切皆网格。** 所有功能入口、物品列表、配方选择、地点导航、战斗操作均以网格形式呈现。点击格子有下级内容的，进入下级网格；无下级的，弹出操作面板。

### 1.2 网格规格

| 属性 | 规范 |
|------|------|
| 横向列数 | 固定 **4 列**（主网格）/ 3 列（操作子网格） |
| 格子尺寸 | 统一，自适应屏幕宽度（750 设计分辨率下约 172×172px） |
| 格子内容 | 图标（可选）+ 名称文字 + 数量角标（右上）+ 状态边框色 |
| 纵向排布 | 自适应行数，超出则 ScrollView 垂直滚动 |
| 间距 | 格间 8px，边距 16px |

### 1.3 格子状态

| 状态 | 视觉表现 | 说明 |
|------|----------|------|
| 可用 | 正常边框 + 白色底 | 可点击进入 |
| 选中 | 高亮边框（主题色） | 当前焦点 |
| 禁用 | 灰色边框 + 半透明 | 条件不满足（如材料不足） |
| 新增 | 红点角标 | 有新内容/未读 |
| 冷却 | 覆盖灰色进度遮罩 | 显示剩余冷却时间 |

### 1.4 交互规则

| 操作 | 行为 |
|------|------|
| 点击格子 | 有下级 → 进入下级网格；无下级 → 弹出操作面板 |
| 长按格子 | 快捷操作菜单（使用/装备/详情/丢弃） |
| 左上角返回 | 返回上一级网格 |
| 顶部面包屑 | 显示当前路径（主页 > 制造 > 制造台） |
| 滑动手势 | 网格内容纵向滚动 |

## 二、完整网格导航树

### 2.1 一级网格（主页）

4 列 × 3 行布局，顶部常驻状态栏：

```
┌─────────────────────────────────────┐
│  状态栏：体温|满腹|水分|HP|体力|精神   │
│  时间：春第1日 早晨                   │
├─────────────────────────────────────┤
│  [ 状态 ]  [ 背包 ]  [ 制造 ]  [ 烹饪 ] │
│  [ 建筑 ]  [ 地图 ]  [ 贸易 ]  [ 技能 ] │
│  [ 地牢 ]  [ 任务 ]  [ 菜单 ]  [ 战斗*] │
└─────────────────────────────────────┘
```

> *战斗格仅在遇敌时高亮可点，平时灰显

### 2.2 二级网格清单

| 一级入口 | 二级网格内容 | 格子数量 | 说明 |
|----------|-------------|----------|------|
| 状态 | 详情面板（非网格） | - | 6 维状态数值 + 描述 |
| 背包 | 物品网格 | 动态 | 按类型分 Tab：全部/装备/食物/材料/药剂/工具 |
| 制造 | [制造台][炼金台][秘术台][科研台][酿酒桶] | 5 | 按已建造的工作台显示 |
| 烹饪 | 食材选择网格 | 动态 | 选 2 个食材 → 自动匹配配方 |
| 建筑 | 已有建筑网格 | 动态 | 每格=1 建筑，显示等级 |
| 地图 | 地点网格 | 动态 | 按已解锁地点显示 |
| 贸易 | 商人网格 | 动态 | 按当前可交易商人显示 |
| 技能 | [天赋][格斗][射击][防御][敏捷][魔法][耕种][酿酒] | 8 | 按技能类别 |
| 地牢 | 楼层网格 | 动态 | 已探索楼层 |
| 任务 | 任务网格 | 动态 | 进行中/已完成 |
| 菜单 | [存档][设置][转生][统计][帮助] | 5 | 系统功能 |
| 战斗 | 战斗操作网格 | 4 | [攻击][技能][道具][逃跑] |

### 2.3 三级网格清单（关键路径）

#### 制造路径
```
制造 → [制造台] → 配方网格
                    ├ [斧头] → 详情面板（材料需求 + 数量 + 制造按钮）
                    ├ [镐子] → 详情面板
                    ├ [绳子] → 详情面板
                    └ [更多配方...]
      → [炼金台] → 药剂配方网格
      → [秘术台] → 魔法配方网格
      → [科研台] → 科技研发网格
      → [酿酒桶] → 酿酒配方网格
```

#### 地图路径
```
地图 → [森林] → 行动网格：[采集][狩猎][砍伐][探索][返回]
      → [矿洞] → 行动网格：[挖矿][探索][返回]
      → [河流] → 行动网格：[钓鱼][取水][探索][返回]
      → [集市] → 行动网格：[交易][任务][返回]
      → [墓地] → 行动网格：[搜索][探索][返回]
      → [地牢入口] → 进入地牢系统
      → [更多地点...]
```

#### 背包路径
```
背包 → Tab: [全部][装备][食物][材料][药剂][工具]
      → 物品网格（每格=1 物品堆叠）
          → [斧头×1] → 操作网格：[使用][装备][丢弃][详情]
          → [水×2]   → 操作网格：[使用][丢弃][详情]
          → [面包×2] → 操作网格：[食用][丢弃][详情]
          → [装备类] → 操作网格：[装备][卸下][详情]
```

#### 建筑路径
```
建筑 → 已有建筑网格
      → [制造台 Lv.0] → 操作网格：[使用][升级][详情]
      → [炊具 Lv.2]   → 操作网格：[使用][升级][详情]
      → [大箱子 Lv.5] → 操作网格：[打开][升级][详情]
      → [农田×2]      → 农田网格：[农田1][农田2] → [种植][收获][详情]
      → [陷阱×2]      → 陷阱网格：[陷阱1][陷阱2] → [查看][重置][详情]
```

#### 技能路径
```
技能 → [天赋] → 天赋网格：[拾荒者][幸运儿][耐久][体能][商业][经营][战斗专家]
                → 每格 → 详情面板（效果 + 当前等级 + 升级消耗 + 升级按钮）
      → [格斗] → 升级面板（教师位置 + 费用 + 升级按钮）
      → [射击] → 升级面板
      → [防御] → 升级面板
      → [魔法] → 升级面板
      → ...
```

#### 贸易路径
```
贸易 → 商人网格（按刷新周期显示）
      → [伐木工] → 交易网格：[木材×40] → 详情面板（价格 + 购买数量 + 确认）
      → [矿工]   → 交易网格：[铁矿×40][水晶×6][宝石×3]
      → [猎人]   → 交易网格：[肉×40][皮毛×10][羽毛×40]
      → [商队]   → 交易网格：[金币×200]
```

#### 地牢路径
```
地牢 → 楼层网格：[1F][2F][3F]...[当前层]
      → [当前层] → 行动网格：[前进][搜索][休息][使用卷轴][返回]
                   → 遇敌 → 战斗网格
                   → 发现宝箱 → 操作网格：[开启][跳过]
                   → 地牢商人 → 交易网格
```

#### 烹饪路径
```
烹饪 → 食材选择网格（选第 1 食材）
      → [肉] → 食材选择网格（选第 2 食材）
               → [水] → 匹配结果：肉汤 → [确认烹饪]
               → [蔬菜] → 匹配结果：蔬菜肉 → [确认烹饪]
               → [面包] → 无匹配 → [重新选择]
```

### 2.4 战斗网格（触发式）

```
┌─────────────────────────────────────┐
│  怪物：蝙蝠  HP: ████░░░░  50/100     │
│  玩家：HP: ████████  100/100          │
├─────────────────────────────────────┤
│  战斗日志：                           │
│  你用斧头攻击蝙蝠，造成 23 伤害       │
│  蝙蝠咬了你，造成 8 伤害              │
├─────────────────────────────────────┤
│  [ 攻击 ]  [ 技能 ]  [ 道具 ]  [ 逃跑 ] │
└─────────────────────────────────────┘
```

- **攻击** → 直接普通攻击
- **技能** → 技能网格：[格斗技][魔法技][射击技] → 选择后释放
- **道具** → 战斗道具网格（从背包筛选可用道具）
- **逃跑** → 概率成功逃跑

### 2.5 事件/剧情网格

事件触发时以弹窗网格形式呈现选择：

```
┌─────────────────────────────────────┐
│  事件：流浪汉                        │
│  "给我一些食物，我教你看星星"         │
├─────────────────────────────────────┤
│  [ 给面包 ]  [ 给肉 ]  [ 拒绝 ]  [ 离开 ] │
└─────────────────────────────────────┘
```

## 三、技术架构

### 3.1 网格组件体系

```
GridComponent (通用网格容器)
├── 属性
│   ├── columns: number        // 列数（默认 4）
│   ├── dataSource: GridItem[] // 数据源
│   ├── cellTemplate: Prefab   // 格子预制体
│   └── onCellClick: Function  // 点击回调
├── 子组件
│   ├── GridCell (格子单元)
│   │   ├── icon: Sprite       // 图标
│   │   ├── label: Label       // 名称
│   │   ├── countBadge: Label  // 数量角标
│   │   ├── stateBorder: Sprite// 状态边框

│   └── BreadcrumbNav (面包屑导航)
│       ├── path: string[]     // 路径栈
│       └── onBack: Function   // 返回回调
```

## 五、网格化设计优势

| 优势 | 说明 |
|------|------|
| 触控友好 | 格子尺寸大，手指点击精度要求低 |
| 信息密度高 | 4 列网格一屏可展示 12+ 入口 |
| 层级清晰 | 面包屑导航 + 返回按钮，不会迷失 |
| 统一交互 | 所有功能操作一致：点格→网格/面板 |
| 开发高效 | 通用 GridComponent 复用，减少 UI 开发量 |
| 扩展方便 | 新增功能只需加格子 + 绑定数据 |

## 七、风险与应对

| 风险 | 等级 | 应对 |
|------|------|------|
| 数据层迁移遗漏 | 中 | 编写数据校验脚本，自动化比对 |
| 事件系统逻辑复杂 | 高 | 先画事件流程图，逐条迁移测试 |
| 网格 UI 工作量大 | 中 | 通用 GridComponent 复用，优先核心面板 |
| 包体超限 | 低 | 数据分包 + 资源压缩 |
| 烹饪配方匹配 | 中 | 对照原 COOK_DATA 逐条验证 |
| 战斗平衡性 | 中 | 对照原游戏数值测试 |

---

_网格化方案的最大优势是开发效率——一套 GridComponent 覆盖 90% 的 UI 场景，剩下的详情弹窗和战斗界面单独做。预计阶段三 UI 层的实际工作量会比传统 UI 方案少 30%-40%。_
