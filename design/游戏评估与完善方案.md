## 0. 一句话结论

**工程交付度已达 ~95%，但"游戏作为微信小游戏产品"的设计是空白的。** 当前最大风险不是 bug，而是三个未决的产品问题：①为谁做（目标用户 / 单局时长未定义）、②为什么回来（留存钩子缺失）、③怎么活（变现零设计）。

建议定位为 **「硬核内核 + 移动外壳」**：保留"超苦逼"的系统深度与稀缺感（这是乐趣内核，不软化难度），补上移动端外壳（新手引导 / 离线收益 / 日活钩子 / 音频 juice / 轻变现）。先清 4 类上线硬门槛，再补留存与变现。

## 1. Fun Hypothesis 与设计支柱（移植时跳过的地基）

原版 KuBi 的 fun 内核：**在稀缺与残酷下，靠系统精通一点点挤出进展的"苦修式"权力幻想**；转生（roguelite meta）提供长期意义。乐趣来自 *system mastery under scarcity*，不是数值堆砌，也不是"爽快战斗"。

但移植方案从未把这条"乐趣"重新落到**微信移动端**——直接 1:1 搬了 PC 硬核循环。这是根本张力：

- PC 上，"超苦逼"（受苦）是玩家**主动选择**的硬核魅力；
- 微信上，同样的高摩擦循环 + 推送打断 + 短会话，会变成**劝退**。

→ 必须补写移动端 Design Pillars（见 §4 路线图）。移植时缺这步，导致后面所有"完善"都缺少统一评判基准。

## 3. 三个必须老板拍板的产品岔路

> 品类 = 文字沙盒生存 / 放置；平台 = 微信小游戏 + 网页双端（已定）。但**目标用户、单局时长、变现模式**三者未定义，所有"完善"细节都依赖它们。

### 岔路①：战略定位
- **A 忠实移植**（服务原 PC 硬核粉）：低风险、低天花板、可最快上架；社区口碑型，量小。
- **B 移动化改造**（扩圈休闲移动用户）：高天花板；需重设节奏 + 留存 + 变现，重平衡成本中高。
- **C（推荐）硬核内核 + 移动外壳**：保留"超苦逼"系统深度与稀缺感（乐趣内核，不软化难度），加移动外壳（引导 / 离线收益 / 日活 / 音频 juice / 轻变现）。风险可控、天花板居中偏上。

### 岔路②：变现模式
- **广告**（激励视频复活 / 双倍产出 + 插屏）——最适合放置类，不破坏生存幻想。
- **内购 IAP**（去广告 / 资源礼包 / 外观）。
- **暂不变现**，先做口碑与留存基线。
- 设计师提示：当前 gold 唯一稳定 sink 是天赋技能（有上限）。若上 IAP 卖 gold 会直接通胀——**变现必须配套新增 gold sink**（建筑升级 / 地牢钥匙 / 转生消耗）。

### 岔路③：首版范围
- **最小可上线**：P0 清障 + 音频 SFX + 最小引导。
- **完整首版**：含留存日活 + 社交 / 排行 + 平衡重调。

## 5. 关键系统活检（设计待办，非工程）

1. **gold 经济闭环单薄**：唯一稳定 sink = 天赋技能（`ActionSkill.ts:62,91`，`cost+costInc×lv`，有上限）。后期 gold 无去处 → 通胀 / 无意义。**需补 sink**：建筑升级消耗、地牢钥匙、转生消耗、或商人回收。
2. **D2 砍 farm 的连锁**：地图怪递减后，原"无限刷某地图怪"速刷流被砍（裁决 §5.5）。需确认材料 / gold 的合法替代 farm 点，否则制造链 / 经济断供。
3. **离线 = 0 处理**（grep 全仓 0 命中）：作为"放置挂机"游戏却无离线推进，与品类自相矛盾；移动端这是留存核心，必须设计。
4. **事件战斗公平性（D1）**：维持现状 = 事件中强怪无逃跑 = 必死陷阱，体感"被脚本谋杀"，损害信任。
