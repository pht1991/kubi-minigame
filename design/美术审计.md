## 1. 视觉一致性审计

### 1.1 配色系统（优点）

- ✅ 已有**集中化 token 体系**：`theme.ts` 的 `C`（颜色）、`S`（尺寸/间距）、`Btn`（按钮预设）三处收口，注释明确「禁止再写 `new Color(...)` 字面量」。这是非常好的工程基线。
- ✅ 暖羊皮纸主题（米黄 `panelBg 255,248,240` + 暖棕 `panelBorder 200,168,130`）贯穿面板 / 底栏 / Toast / 存档指示器，整体气质统一。
- ✅ 语义命名清晰：`accent/accent2/tabOn/tabOff/danger/warn/disabled/cellSelected/cellCooldown/durHigh|Mid|Low` 等，意图可读。

## 2. 可访问性分级

### 2.1 设备尺寸换算模型（关键前提）

- 画布策略：`view.setDesignResolutionSize(750, 1334, ResolutionPolicy.FIXED_WIDTH)`（`MainScene.ts:269`）——**宽度固定 750，高度随设备比例变化**。
- 折算假设：在典型 ~390pt 宽机型（@3x 物理 1170px）上，750 设计宽铺满屏幕，即 **1 设计 px ≈ 0.5 CSS pt**（保守取整）。
  - 例：20 设计 px ≈ 10pt；44pt 触摸目标 ≈ **88 设计 px**。
- ⚠️ 该比例随机型变化；**首版建议以「设计 px」为硬指标**，下文阈值均用设计 px 并附 pt 参考，主理人可按真机实测微调。

### 2.2 三级特性矩阵

| 维度 | Basic（最低可上线） | Standard（首版建议达成） | Comprehensive（打磨目标） |
|------|------|------|------|
| **字号下限** | 全局最小 ≥14 设计 px（≈7pt）；正文 ≥18 | 全局最小 ≥16（≈8pt）；正文 ≥20 | 全局最小 ≥18；正文 ≥22；提供「大字号」模式（×1.15~1.3 系数） |
| **对比度** | 关键文字 ≥3:1；禁用态豁免 | 全部文字 ≥4.5:1；禁用态 ≥3:1 | 4.5:1 + 可选高对比主题（深色描边/加深底） |
| **触摸目标** | 主可点元素高 ≥56 设计 px（≈28pt） | 主可点元素高 ≥72 设计 px（≈36pt） | ≥88 设计 px（44pt，iOS HIG） |
| **长文本** | 不允许 CLAMP 截断，至少 SHRINK 缩字 | 长文本 wrap 换行不截断；关键文本不被 Mask 裁切 | 同上 + 字号放大后仍不截断 |
| **状态可辨** | disabled 明显区分（灰+降透明） | disabled + selected + 警告三态均有清晰视觉 | 增加 pressed/hover 即时反馈 |
| **可读辅助** | 无 | 字号/对比度达标 | 高对比主题、动态字号、关键数值加粗 |

### 2.3 对比度量化表（WCAG 核算，背景取面板/卡片浅底）

| 组合 | 对比度 | 判定 |
|------|------|------|
| body(50,40,30) on panelBg | **~13.7:1** | ✅ 优秀 |
| title(92,61,30) on panelBg | ~15:1 | ✅ |
| sub(120,100,80) on panelBg | **~5.3:1** | ✅ 过 AA |
| cellCount(150,110,70) on cellBg | **~4.3:1** | ⚠️ 临界未过 4.5 |
| white on confirm(accent2 绿) | ~4.7:1 | ✅ |
| white on primary(accent 橙) | **~3.1:1** | ❌ 未过 4.5（仅达大字号 3:1，但按钮字非大字号） |
| white on Tab 选中(tabOn) | **~2.3:1** | ❌ 严重不达标 |
| disabled 文字 on disabled 底(UIButton) | **~1.5:1** | ❌ 几乎不可见 |
| optionTextDisabled on optionBgDisabled | ~2.3:1 | ⚠️ 禁用豁免但偏弱 |
| white on danger(红) | ~5.3:1 | ✅ |
| 纯红徽标 on cellBg | ~3.5:1 | ⚠️ 对比尚可但色冲突 |

### 2.4 首版应达到的等级

- **最低级（硬门槛，必须达标才能上架）**：达到 **Basic** 全部 + 修复全部 🔴 P0（禁用态可读、选中态统一、durText 下限、主按钮/选中 Tab 文字对比度）。
- **建议级（推荐首版即达成）**：冲击 **Standard**——全局文字 ≥4.5:1、主可点元素高 ≥72 设计 px、长文本 wrap 不截断、state 三态清晰。网页端（PC/大屏）用户更多样，Standard 是双端稳妥线。
- **打磨期（后续迭代）**：Comprehensive 的动态字号 + 高对比主题。

## 3. 打磨期美术 / 可访问性待办清单（供排期）

### P0 — 首版必修（阻断上架）

1. **统一禁用态视觉**：新增 `C.disabledText` 与 `C.disabledBg` 令牌，禁用态文字对比度 ≥3:1（深色灰字 + 浅灰底），替换 `UIButton.ts:51`、`EventDetailPanel.ts:35`、`theme.danger` 边框硬编码。
2. **消除选中态颜色冲突**：`theme.cellSelectedBg/Stroke`（浅蓝）与 `GridComponent` 暖杏金二选一，**统一为暖色系**（推荐金/杏），改 `theme.ts:65-66` 或 `GridComponent.ts:430-434`。
3. **抬高 durText 字号**：`theme.font.durText` 10 → ≥16 设计 px（≈8pt），确保耐久数值可读（`theme.ts:149`）。
4. **修复主按钮/选中 Tab 文字对比度**：primary(accent)、Tab 选中(tabOn) 白字未达 AA；方案二选一——加深底色，或改用深色文字（`accent`/`tabOn` 上用 `C.title` 深棕字），使正文级文字 ≥4.5:1。

### P1 — 建议首版达成（Standard）

5. **收敛 hardcode 颜色到 theme**：`BagPanel` 分类色、`EventDetailPanel` DIALOG_*/DISABLED、`GridComponent` fromHEX 色、`ModalInfoRow`/`ModalRow` 默认色、`MainScene` 状态栏底色/文字，全部改为 `C` 令牌或新增语义令牌（如 `C.catWeapon/C.catFood…`、`C.infoRowBg/C.infoLabel`），消除漂移。
6. **长文本防截断**：`ModalPanel.mkText/mkInline/mkCenter` 与 `ModalInfoRow` 对动态文案统一 `wrap:true`（或 `shrink:true`），禁止 CLAMP 截断（`ModalPanel.ts:283,298`、`ModalInfoRow.ts:48`）。
7. **触摸目标高度达标**：底栏按钮 72h、选项行 70h 提升到 ≥72~88 设计 px；`UIButton` 默认 `h=52`、`ModalRow` 图标最小 `52` 提高到 ≥72（`MainScene.ts:755`、`theme.optionH:130`、`ModalRow.ts:54`、`UIButton.ts:22`）。
8. **微调 cellCount 对比度**：`theme.cellCount` 加深（如 `120,85,55`）使其 ≥4.5:1。
9. **补充可点行反馈**：`ModalRow`/`ModalInfoRow` 增加 pressed（按下变深/缩放下沉）与选中高亮视觉（`docs/弹窗体系分析.md:91` 已知缺口）。

### P2 — 打磨增强（Comprehensive）

10. **动态字号 / 高对比模式**：提供「大字号」开关（整体 ×1.15~1.3）；因全 Canvas 绘制不可接读屏，以高对比主题 + 字号放大作为无障碍替代。
11. **纯红徽标改用令牌**：`GridCell.ts:101` 的 `255,0,0` 改为 `C.warn`/`C.danger` 体系色。
12. **状态色规范文档**：把 disabled / selected / cooldown / warning / danger 的语义与令牌集中注释或独立 token 文档，供后续面板遵循。
13. **跨面板字号复核**：复核战斗面板 / 各弹窗标题(28)与正文层级，确保面板间一致。

## 4. 给主理人的排期建议（一句话）

> 首版**必须先清 4 个 P0**（禁用态可读、选中态统一、durText 下限、主按钮对比度），这是「能上线」的硬门槛；P1 是双端（尤其网页）体验达标的性价比区，建议随首版一并做掉。
